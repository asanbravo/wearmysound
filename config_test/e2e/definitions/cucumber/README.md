## Getting Started with run Carrier Departure Core tests

You can run acceptance tests by executing the next script:
~~~
$ ./run-carrier-departure-core-tests.sh
~~~

In fact, you can add these flags to the script:
1) skipBuild -> if you do not need to build the docker image of the service

Example:
~~~
$ ./run-carrier-departure-core-tests.sh skipBuild
~~~
